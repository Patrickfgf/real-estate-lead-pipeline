# Projeto Jaré

Pipeline que ingere leads de 2 portais imobiliários (Wimóveis via **webhook** oficial e DFImóveis via **API** oficial), limpa, deduplica e enriquece os dados, armazena em **DuckDB**, pontua a qualidade do lead e carrega no **Trello** + um **dashboard**, orquestrado num servidor.

> 🚧 Em construção.
>
> **Stack:** Python · FastAPI · DuckDB · pandas · Streamlit · Trello API
